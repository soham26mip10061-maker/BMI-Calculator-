1) BMI Health Companion

-->A simple Python-based BMI Calculator made as a college project.

The program calculates Body Mass Index (BMI) based on the user's height and weight and provides basic health information.

2)Features

* Calculate BMI
* Supports different height units:
> Meter
       > Centimeter
       > Feet and Inches
* Takes user's name as input
* Shows calculated BMI
* Displays BMI category
* Simple menu-based interface
* Beginner friendly

3) Technologies Used

* Python 3
* Input and Output
* If-else statements
* Loops
* Mathematical operations
* Functions

4) How to Run

Make sure Python 3 is installed on your computer.

Run the program using:

-->bash
-->Python  main.py

5)How It Works

The program asks the user for their name, height and weight.

The user can select the height unit:

1. Meter
2. Centimeter
3. Feet and inches

The program converts the height into meters and calculates BMI using:

BMI = Weight (kg) / Height² (m)

After calculation, the program displays the BMI value and its category.

 6)BMI Categories

Below 18.5 - Underweight

18.5 to 24.9 - Normal

25 to 29.9 - Overweight

30 or above - Obesity

Note: BMI is only a basic screening measure and does not give a complete picture of a person's health.
